# House Audio Server v0.14.3

Packaging and installation explicitly authorized on 2026-11-21. This release
packages the unmuted-controller session policy from main commit
`4d15c92d8661bdd8664a11f25dc04dd0c7f0fc4f`, on the integrated CD/browser/subwoofer
baseline. It changes no further playback behavior beyond that authorized policy.

## Behavior

Only an unmuted controller holds the session, including while paused. Muted
controllers remain connected for controls. When only muted controllers remain,
a playing library track drains to its normal end; a paused controller-held
session ends without advancing. Unmuting after session completion does not
restart the old session. Other nodes, physical CD retention, manual transport
rules and receiver recovery follow the behavior documented in
[UNMUTED_SESSION_RETENTION.md](UNMUTED_SESSION_RETENTION.md).

## Package and installation

- Package: `HouseMusic_Server_v0.14.3_Pi.zip`, generated by
  `python3 tools/package_pi.py --output-dir <destination>` from clean committed
  source. It includes the complete integrated runtime, CD gateway, browser,
  service/config templates, installation/rollback scripts and release notes.
- `SOURCE_SHA.txt` and `MANIFEST.json` identify the exact commit/tree and file
  hashes. The builder checks each packaged file against its committed bytes and
  verifies the finished ZIP. Untracked caches and local files are excluded.
- Runtime version and both installer guards now require `0.14.3`. The existing
  full-server installer backs up server/gateway, preserves configured defaults,
  and rolls back on failed installation checks. The final check compares
  installed source/assets/gateway bytes with the package and requires healthy
  service dependencies, the browser CD controls and the updated session API.
- `install-cd.sh` remains the full-server entry point; see `INSTALL_CD.txt`.
  Restart interrupts playback and applies the existing fresh-session boundary.
- GitHub packaging remains manual-only on main. Its explicit input gate is now
  `AUTHORIZE_SERVER_PACKAGE`; ordinary pushes/PRs run checks only.
