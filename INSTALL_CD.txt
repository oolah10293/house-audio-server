HOUSE MUSIC SERVER v0.14.3 — RASPBERRY PI UPDATE
================================================

Only unmuted phones/controllers now keep a house session open, including while
paused. Muted phones remain available for browsing and controls. When only muted
controllers remain, a playing library track finishes and the session ends; an
already-paused controller-held session ends without advancing the song.

This is the complete integrated server: browser controls, radio, Resume Playlist,
CD input/automatic takeover, library sorting and subwoofer support are included.
The existing physical CD no-speaker retention rule remains in effect.

INSTALL FROM THIS ZIP
  1. Copy HouseMusic_Server_v0.14.3_Pi.zip to the Pi.
  2. In the directory containing the ZIP, run:
       unzip HouseMusic_Server_v0.14.3_Pi.zip
       cd HouseMusic_Server_v0.14.3
       sudo sh ./install-cd.sh

The install-cd.sh filename is retained from the existing full-server installer.
It backs up both server and gateway, installs the matching files, restarts both
services and checks the actual installed files, version, health, browser and
session-policy API. A failed installation check restores the backup.

REQUIREMENTS AND EFFECT
  - Existing House Music in /opt/house-audio-server.
  - Existing CD gateway service house-audio-input-gateway.service, with its Python
    file at /home/ads-suck/gateway.py and its API listening on port 8768.
  - Python 3, systemd and unzip.
  - Installation interrupts current playback. The normal server restart policy
    clears the current MPD queue and starts a fresh session if a passive node is on.
  - Existing /etc/default/house-audio-server and persistent settings are preserved.
  - The installer reports the backup directory under /var/backups/house-audio-server.

VERIFY
  Success ends with:
    Installed House Music 0.14.3; browser, service and session policy verified.
  Open http://192.168.1.12:8787/ and check playback.
  Check a lone paused phone unmuted, then muted. Check that muting a phone while
  another room is playing does not disturb that room.
  SOURCE_SHA.txt identifies the exact committed source included in this package.
  MANIFEST.json records each packaged source file's SHA-256.

ROLL BACK
  From this extracted folder, run:
    sudo sh ./rollback-cd.sh
  This restores the newest complete backup produced by this installer.
