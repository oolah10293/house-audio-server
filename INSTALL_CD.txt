HOUSE MUSIC SERVER v0.14.8 — RASPBERRY PI UPDATE
================================================

CD-eject restoration policy: when the LiteOn reports confirmed no_disc, the
previous library/position or radio is restored WITHOUT automatic playback
when at least one session-retaining node remains connected. Press Play to
resume it. With no retaining nodes, CD eject clears the old session; the
next passive node starts the configured default folder with a fresh shuffle.
Inserting a new disc still takes over and plays track 1. Ordinary CD
heartbeats do not reclaim playback; multiple disc cycles keep the original
pre-CD bookmark. Normal CD-player power-off restoration remains unchanged.
No ESP32 firmware, ADC stream, MPD binary or Snapcast changes are included.

Sources Phase 1: the former CD Players sidebar entry is now Sources.
The page shows actually registered CD, Analog/Line-in and Other devices.
Select the Lite-On CD player to expand its original numbered track controls.
Analog and other source types are discoverable but do NOT yet play audio.
The prior v0.14.6 Sources UI remains unchanged in this update.

This is the complete integrated server: browser controls, radio, Resume Playlist,
CD input/automatic takeover, library sorting and subwoofer support are included.
The existing physical CD no-speaker retention rule remains in effect.

INSTALL FROM THIS ZIP
  1. Copy HouseMusic_Server_v0.14.8_Pi.zip to the Pi.
  2. In the directory containing the ZIP, run:
       unzip HouseMusic_Server_v0.14.8_Pi.zip
       cd HouseMusic_Server_v0.14.8
       sudo sh ./install-cd.sh

The install-cd.sh filename is retained from the existing full-server installer.
It backs up both server and gateway, installs the matching files, restarts both
services and checks the actual installed files, version, health, browser and
session-policy API. A failed installation check restores the backup.

REQUIREMENTS AND EFFECT
  - Existing House Music in /opt/house-audio-server.
  - Existing CD gateway service house-audio-input-gateway.service, with its Python
    file at /home/ads-suck/gateway.py and its API listening on port 8768.
  - Python 3, systemd and unzip.
  - Installation interrupts current playback. The normal server restart policy
    clears the current MPD queue and starts a fresh session if a passive node is on.
  - Existing /etc/default/house-audio-server and persistent settings are preserved.
  - The installer reports the backup directory under /var/backups/house-audio-server.

VERIFY
  Success ends with:
    Installed House Music 0.14.8; browser, service and session policy verified.
  Open http://192.168.1.12:8787/ and check playback.
  Open Sources (formerly CD Players). The Lite-On should appear in CD players.
  Select Lite-On to expand numbered CD tracks and try a track; select it
  again to collapse the tracks. Existing CD auto-takeover must still work.
  Analog/Line-in and Other sections appear only when devices register.
  These future device types should show "Playback not available yet", not Play.
  Check Library, Queue, Speakers and current music playback as before.
  With a connected speaker, eject a CD and verify the prior music is
  restored PAUSED. Press Play to resume. Insert another CD and confirm
  automatic track-one takeover, then eject again and confirm paused return.
  With no session-retaining nodes, eject and confirm idle/empty session;
  power on a passive speaker to confirm a fresh default-folder shuffle.
  The installer verifies services and that the new Sources UI was served.
  SOURCE_SHA.txt identifies the exact committed source included in this package.
  MANIFEST.json records each packaged source file's SHA-256.

ROLL BACK
  From this extracted folder, run:
    sudo sh ./rollback-cd.sh
  This restores the newest complete backup produced by this installer.
